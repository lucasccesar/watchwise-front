# Footer

Rodapé de site institucional/marketing, conforme Footers.pdf. **Uso condicionado**: os anexos mostram um rodapé de site de marketing (colunas de links, newsletter, CTA) — se o Watchwise for apenas um app logado (sem páginas institucionais), este componente provavelmente não se aplica. Confirmar antes de implementar.

## Composição

Logo + colunas de links categorizados ("Product", "Company", "Resources", "Social", "Legal") + linha de copyright. Variações incluem bloco de newsletter ("Enter your email" + botão "Subscribe"), CTA de conversão, e versão compacta (uma linha de links + copyright).

## Estilo

Fundo `surface` ou `surface-secondary`; links em `text` (hover `primary`); texto de copyright em `tertiary`, `text-xs`.

## Uso

Se aplicável, usar apenas nas páginas institucionais (ex. "Sobre", "Ajuda") — não no app logado.
