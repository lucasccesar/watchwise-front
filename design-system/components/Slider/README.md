# Slider

Seleção de valor (ou faixa de valores) em uma escala contínua, conforme Sliders.pdf.

## Variantes

- **Valor único** — trilho `surface-secondary`, preenchimento até o handle em `primary`, handle circular `text` com borda `primary`.
- **Faixa (range)** — dois handles, preenchimento `primary` entre eles.

## Estados

Default, hover (handle levemente maior), focus (anel de foco no handle), disabled (opacidade reduzida).

## Uso

Use para valores numéricos contínuos onde a posição relativa importa mais que o valor exato digitado (ex. volume, progresso manual). Para valores exatos digitáveis, prefira `Inputs`.
