# Messaging

Conversa/chat (bolhas de mensagem), conforme Messaging.pdf. **Uso condicionado**: não identificado nas telas aprovadas do Watchwise (*Watchwise Initial Pages.pdf*) — incluir apenas se o produto tiver uma feature de comentários/DM; confirmar antes de implementar.

## Composição

- **Mensagem recebida** — bolha à esquerda, fundo `surface-secondary`, avatar + nome + timestamp acima.
- **Mensagem enviada** — bolha à direita, fundo `primary`, texto `text`.
- **Reações** — chips pequenos abaixo da bolha.
- **Anexo** — cartão com ícone/miniatura + nome do arquivo.
- **Composer** — campo de texto + botão de enviar, fixado na base do painel.

## Painel de conversa em grupo

Cabeçalho com abas "Mensagens" / "Participantes".

## Uso

Textos em `text-sm`; timestamps em `text-xs`/`tertiary`.
