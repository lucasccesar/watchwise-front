# Header / Navigation

Barra de navegação superior, conforme Header.pdf. Duas aplicações distintas nos anexos — não misture:

## Barra do produto (in-app) — fonte primária: Watchwise Initial Pages.pdf

A tela aprovada já define a composição real do topo do app: logo à esquerda, busca central, ícones de ação e avatar do usuário à direita, sobre `surface`. **Siga exatamente a referência aprovada** para esta barra — Header.pdf serve apenas como fonte dos átomos reutilizáveis abaixo (estados de item de menu), não como layout do header do produto.

## Átomos reutilizáveis (Header.pdf)

- **Item de navegação** — texto (`text-sm`, 600) com chevron opcional; estados default/hover (`surface-secondary`)/selecionado (`primary`); com ou sem ícone/badge "New" à esquerda/direita.
- **Ícone de menu mobile** — hambúrguer ↔ X, estados default/hover/selecionado.
- **Mega-menu** (painel suspenso sob um item) — variações: lista simples, lista + descrição, lista + cartão promocional (imagem + texto + CTA), lista + categorias (colunas "Get started"/"Resources"/"Support") + rodapé de ações, lista + posts recentes com miniatura.

## Uso

Mega-menu documentado é de contexto de marketing — **uso condicionado**: aplicável apenas se o Watchwise tiver páginas institucionais com navegação complexa; o app logado usa a barra já aprovada.
