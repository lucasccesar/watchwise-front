# Progress

Indicador de andamento, conforme Progress.pdf.

## Variantes

- **Barra linear** — trilho `surface-secondary`, preenchimento `primary`, cantos arredondados (raio provisório). Rótulo de porcentagem opcional ao lado ou acima.
- **Anel (radial)** — mesmo par de cores, traçado circular; usado para indicadores compactos (ex. progresso de um card, avatar com progresso — ver Avatar).

## Estados

Determinado (com valor 0–100%) é o único estado documentado nas páginas anexadas — não há um padrão indeterminado (loading infinito) visível nos anexos.

## Uso

Use a barra para progresso em listas/telas largas; o anel para indicadores compactos sobrepostos a outro elemento (ex. avatar, card pequeno). No Watchwise, aplicável a "episódios assistidos de uma temporada" ou "progresso de meta anual de filmes".
